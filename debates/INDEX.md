## Status definitions

- SCHEDULED — created but not started.
- ACTIVE — currently in progress.
- COMPLETED — finished.
- CANCELLED — cancelled before completion.

Only one session should normally be ACTIVE at a time.

Each session has its own directory containing:
- CONTEXT.md
- TRANSCRIPT.md
